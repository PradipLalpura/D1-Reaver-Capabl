ChatGPT (remote, needs your token above)

  1. Open Settings → Security and login → Developer mode ON.
  2. Go to chatgpt.com/plugins → +, name it reaver.
  3. Connection URL: https://reaver.antarik.co/mcp/ (+ token when asked).
  4. New chat → tools menu → attach reaver → ask: "find 10 bakeries in Ahmedabad".

Claude Desktop (local, no token)

  1. Download your ready config:
  2. Claude Settings → Connectors → Import the file (or paste into claude_desktop_config.json).
  3. Restart Claude Desktop → chat normally; REAVER tools appear.

Claude Code (one line)

  1. Open a terminal in the REAVER folder.
  2. Run: python scripts/setup_mcp.py --install claude-code
  3. Verify: python scripts/setup_mcp.py --check → 10 live tools.

OpenCode (one line)

  1. Open a terminal in the REAVER folder.
  2. Run: python scripts/setup_mcp.py --install opencode
  3. Restart your OpenCode session.

Cursor (config file)

  1. Download your ready config:
  2. Cursor Settings → MCP → Add → paste the file content (or save as ~/.cursor/mcp.json).
  3. Restart Cursor.

Kimi CLI (one line)

  1. Run: kimi mcp add --transport stdio reaver -- python -m reaver_mcp.server --transport stdio
  2. Verify: kimi mcp list.
